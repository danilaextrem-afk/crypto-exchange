# FreeVPN 0.2.0 — аудит, исправления и проверка

Дата: 5 ноября 2026. Работа продолжает версию 0.1.0 предыдущего разработчика (ветка `freevpn`),
проект не пересоздавался, существующие функции и workflow сохранены.

## 1. Аудит версии 0.1.0 (до исправлений)

**Что было реализовано (код полностью написан):**
- Туннель WireGuard через официальную библиотеку `com.wireguard.android:tunnel` (`GoBackend`, `VpnService`).
- Статус «Подключено» только после рукопожатия WireGuard и реального TCP-запроса через туннель.
- Мониторинг каждые 5 с, переход на резервный сервер после 3 неудач подряд, повторы с паузой 1–30 с.
- Переподключение при смене сети Wi-Fi ↔ мобильная.
- Автовыбор сервера по измерениям (задержка, потери, скорость, нагрузка), кнопка «Измерить все».
- Split Tunneling по приложениям: «Всё через VPN», «Российские приложения напрямую», «Ручной выбор».
- Полный туннель IPv4 + IPv6 (`0.0.0.0/0`, `::/0`), DNS через туннель, keepalive 25 с, MTU 1380.
- Импорт конфигов и JSON-подписки с резервными адресами; ключи в `EncryptedSharedPreferences`.
- Диагностика (задержка, потери, DNS, внешний IP, скорость), журнал событий.
- Скрипты сервера: `server/setup-wireguard.sh`, `server/make-subscription.py`.
- 20 unit-тестов, workflow `Build APK`.

**Собирался ли APK:** нет. Оба запуска CI упали: первый — на шаге установки Android SDK,
второй — на unit-тесте `forcesFullTunnelKeepaliveDnsAndMtu` (19 из 20 тестов прошли, Kotlin-код компилировался).

**Реальные VPN-серверы:** нет ни одного. Встроенных серверов нет намеренно: приложение подключается к серверу,
который пользователь вправе использовать.

## 3. Результаты проверки

### 3.1. Сборка (workflow `Build APK`)

- Unit-тесты: 21 из 21 прошли (JVM).
- Release-APK `FreeVPN.apk` собран: пакет `app.freevpn`, версия 0.2.0 (код 2), minSdk 26 (Android 8), targetSdk 35,
  подпись APK Signature Scheme v2 проверена `apksigner`, нативные библиотеки WireGuard для arm64-v8a, armeabi-v7a, x86_64,
  размер ≈ 15,8 МБ. Разрешения: `INTERNET`, `ACCESS_NETWORK_STATE` и служебное `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`,
  которое AndroidX добавляет само (защищает внутренние приёмники приложения, доступа к данным не даёт).

### 3.2. Сквозные тесты (workflow `E2E on emulator`)

Среда: эмулятор Android 14 (x86_64, Google APIs) на машине GitHub Actions. **Сервер настоящий**:
WireGuard в ядре Linux, установлен скриптом репозитория `server/setup-wireguard.sh`, 2 клиента, выход в интернет
через NAT машины CI. Имитаций туннеля нет: при недоступном сервере тесты падают.

## 4. Что не удалось проверить

- **Реальный телефон.** Проверено только на эмуляторе x86_64 с Android 14. Не проверены ARM-устройства, Android 8–13 и 15–16,
  оболочки производителей (MIUI, One UI и др.), режимы энергосбережения и Doze, работа с выключенным экраном 30+ минут.
- **Реальный интернет-провайдер и Россия.** Сервер стоял на той же машине, что и эмулятор. Блокировки WireGuard
  у российских операторов (DPI), скорость и стабильность на реальных сетях не проверены.
- **«Постоянный VPN» и «Блокировать соединения без VPN».** Исправление сделано по исходному коду библиотеки
  `GoBackend`, но сквозной тест на эту системную настройку не писался.
- **Выбор основной сети на Android 8–11** (по типу сети) — эмулятор Android 14 использует другой путь (системный callback Android 12+).
- **Российские приложения** (банки, Госуслуги и др.): на эмуляторе их нет; совместимость не проверена.
- **«Измерить все»** и подписка по https: в сквозные тесты не входят.
- **Скачивание APK по ссылке:** из среды разработки файлы артефактов и релизов недоступны, поэтому APK проверялся
  в CI (`aapt2`, `apksigner`, установка на эмулятор), а не скачиванием.

## 5. Ограничения

- **Встроенных серверов нет.** Нужен свой сервер (`server/setup-wireguard.sh`) или разрешённый конфиг
  (например, бесплатный тариф Proton VPN — конфиг WireGuard для своего устройства, условия проверяйте у Proton).
- **WireGuard распознаётся DPI** и в России может не работать у части операторов. Обфускация (AmneziaWG, VLESS+Reality)
  не реализована. Для AmneziaWG существует встраиваемая Android-библиотека (`com.zaneschepke:amneziawg-android`, Apache 2.0) —
  возможный следующий шаг.
- **Kill switch** — системная функция Android («Постоянный VPN» + «Блокировать соединения без VPN»). Без неё при
  переключении на **другой** сервер и при смене сети VPN-интерфейс пересоздаётся (так устроен GoBackend), и на долю
  секунды трафик может уйти напрямую. Пока туннель к одному серверу удерживается, утечки нет (проверено). Для полной
  защиты включите обе системные настройки — экран «Ещё» открывает их одной кнопкой.
- **Split Tunneling — по приложениям**, не по сайтам. Банковские приложения могут замечать VPN даже при исключении.
- **Подпись:** без секретов `KEYSTORE_*` каждая сборка подписана новым одноразовым ключом — новую версию
  нельзя поставить поверх старой, нужно сначала удалить старую.
- Ping — время TCP-подключения к 1.1.1.1:443 через туннель, а не ICMP.
- Скорость определяется сервером, каналом и оператором; гарантий нет.
