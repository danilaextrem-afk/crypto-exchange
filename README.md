# FreeVPN (Android)

VPN-клиент для Android на Kotlin + Jetpack Compose с настоящим туннелем WireGuard
(официальная библиотека `wireguard-android`, `VpnService`).

## Честный статус

| Что | Статус |
|---|---|
| Исходный код приложения | написан полностью |
| Сборка APK | **не выполнялась** в среде разработки (нет Android SDK и доступа к его загрузке). Собирается бесплатно на GitHub Actions — см. ниже |
| Компиляция Kotlin-кода | **не проверена**: первая сборка может выдать ошибки, их нужно поправить по логу |
| Unit-тесты | написаны (`app/src/test`), **не запускались**; запускаются автоматически в CI |
| Работа на телефоне, скорость, утечки, банки и Госуслуги | **не проверялись**: для этого нужны реальный сервер и устройство |
| Серверы | в приложении **нет встроенных серверов** (см. раздел «Серверы и бесплатность») |
| Мониторинг Prometheus/Grafana, PostgreSQL | не включены: для личного VPN они лишние |

## Что умеет приложение

- Туннель WireGuard, полный (IPv4 + IPv6), DNS через туннель, keepalive 25 с для мобильных сетей.
- Подключение считается успешным только после рукопожатия WireGuard **и** реальной проверки доступа в интернет через туннель.
  Ложного статуса «Подключено» нет.
- Мониторинг каждые 5 с; после 3 неудач подряд — переключение на резервный сервер. Если все серверы недоступны — повторы с нарастающей паузой (1, 2, 4 … 30 с).
- Переподключение при смене сети (Wi-Fi ↔ 4G/5G). Работает с выключенным экраном, пока система не остановит процесс (режимы экономии батареи могут это делать — добавьте приложение в исключения оптимизации).
- Автовыбор сервера по измеренной задержке, потерям, скорости загрузки и заявленной нагрузке (не по географии).
  Кнопка «Измерить все» реально поднимает туннель к каждому серверу.
- Split Tunneling по приложениям: «Всё через VPN», «Российские приложения напрямую», «Ручной выбор».
  Собственное приложение всегда идёт через туннель (иначе нечем проверять соединение).
- Обновление списка серверов без переустановки: подписка (JSON по https) с резервными адресами.
- Ключи хранятся в `EncryptedSharedPreferences` (Android Keystore). Телеметрии нет.
- Диагностика: задержка, потери, DNS, внешний IP, скорость загрузки/отдачи, журнал событий.

## Ограничения (без приукрашивания)

- **Split Tunneling работает по приложениям, не по сайтам.** Российский сайт в браузере пойдёт через VPN.
- Список российских приложений (`RuApps` в `RoutingPlanner.kt`) — это предположения об именах пакетов. Совместимость ни с одним банком не проверена. Банковские приложения могут блокировать вход при активном VPN в системе даже при исключении — это решается только проверкой на устройстве.
- **WireGuard легко распознаётся DPI** и у части российских операторов может не работать. Для таких сетей нужны обфусцированные протоколы (VLESS+Reality, AmneziaWG) — в этой версии не реализованы.
- Kill switch — функция Android («Постоянный VPN» + «Блокировать соединения без VPN»); приложение открывает нужный экран настроек, но включить это за вас не может.
- Ping — время TCP-подключения к 1.1.1.1:443 через туннель, а не ICMP.
- Скорость определяется вашим сервером, каналом и оператором. Никаких гарантий скорости и стабильности нет.

## Сборка APK бесплатно (GitHub Actions)

1. Создайте бесплатный аккаунт на github.com и **приватный** репозиторий.
2. Загрузите в него содержимое этой папки (включая `.github/`).
3. Откройте вкладку **Actions** → **Build APK** → **Run workflow**.
4. После окончания скачайте файл `FreeVPN-apk` из раздела Artifacts (внутри `FreeVPN.apk`).
5. Если сборка упала — откройте лог, скопируйте ошибку и пришлите мне: я исправлю код.

Чтобы получить постоянную ссылку: создайте тег `v0.1.0` — APK появится в разделе Releases.

**Постоянный ключ подписи** (чтобы обновления ставились поверх старой версии). Создайте один раз:
```
keytool -genkeypair -keystore release.jks -alias freevpn -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.jks
```
Добавьте секреты репозитория `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`. Без них ключ создаётся одноразовым при каждой сборке.

Локально: Android Studio → открыть папку → Build → Build APK, либо `./gradlew assembleRelease` при установленном Android SDK.

## Установка на телефон

1. Скачайте `FreeVPN.apk` на телефон.
2. Разрешите установку из этого источника (Настройки → Приложения → Особый доступ → Установка неизвестных приложений).
3. Установите, откройте, добавьте сервер (вкладка «Серверы»), нажмите большую кнопку и подтвердите запрос VPN.

## Серверы и бесплатность

Бесплатного, быстрого и безлимитного общего VPN-сервера не существует, а чужие серверы без разрешения использовать нельзя. Поэтому приложение подключается к серверу, который вы контролируете. Варианты без оплаты (условия меняются — проверяйте актуальные на сайтах провайдеров):

| Вариант | Плюсы | Минусы |
|---|---|---|
| Oracle Cloud «Always Free» | постоянный бесплатный тариф, большой лимит трафика | нужна банковская карта для верификации, доступность зависит от региона, неактивные аккаунты могут блокироваться |
| Домашний компьютер / роутер с белым IP и WireGuard | бесплатно, полный контроль | скорость ограничена домашним каналом, IP в вашей стране |
| Сервер друга или родственника, который согласен | бесплатно | нужна договорённость; не используйте чужие серверы без разрешения |
| Бесплатные тарифы Google Cloud / AWS / Azure | не требуют платы в пределах лимитов | малые лимиты исходящего трафика или ограничение по времени (часто 1 ГБ в месяц или 12 месяцев) — для постоянного VPN не подходят |

Подробности честно: «полностью бесплатно» работает только для своего железа или своего бесплатного тарифа в пределах его лимитов.

### Установка сервера WireGuard

На VPS с Debian/Ubuntu (от root):
```
bash server/setup-wireguard.sh 51820 3
```
Скрипт создаст сервер и 3 клиентских конфига в `/root/freevpn-clients/`. Откройте UDP-порт в файрволе провайдера.
Один конфиг — одно устройство. Конфиг импортируется в приложении кнопкой «Добавить» или «Файл».

### Подписка (обновление списка серверов)

```
python3 server/make-subscription.py /root/freevpn-clients/*.conf > subscription.json
```
Разместите файл по закрытому https-адресу и укажите его в «Ещё». В файле лежат приватные ключи — не публикуйте его открыто. Формат — `server/subscription.example.json`.

## Структура

```
app/src/main/kotlin/app/freevpn/
  core/    модели, выбор сервера, здоровье туннеля, Split Tunneling, парсер подписки (без Android-зависимостей, покрыто тестами)
  data/    настройки, шифрованное хранилище, репозиторий серверов и подписки
  vpn/     VpnManager (туннель, мониторинг, переподключение, диагностика), TunnelConfigFactory
  ui/      экраны Compose
app/src/test/   unit-тесты
server/         установка WireGuard и сборка подписки
.github/        сборка APK в CI
```

## Что проверять на реальном устройстве (чек-лист)

1. Подключение, отключение, статус «Подключено» только при рабочем интернете.
2. Выключить Wi-Fi / включить мобильный интернет во время работы VPN.
3. Заблокировать экран на 30+ минут, проверить, что туннель жив.
4. «Диагностика»: внешний IP должен совпадать с IP сервера, потери 0 %.
5. Сайт вида dnsleaktest.com: DNS-серверы должны быть не вашего оператора.
6. Остановить `wg-quick@wg0` на сервере: приложение должно перейти на резервный сервер или в «Переподключение».
7. Режим «Российские приложения напрямую»: открыть каждый нужный банк/сервис и записать результат.
